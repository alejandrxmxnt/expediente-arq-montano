ACTORES:

* USUARIO - donde se determina el rol del usuario para obtener diferentes controles
* CLIENTE - quien realiza la compra de la venta.

CANDIDATOS A SER CLASE

* CATEGORIA
* PRODUCTO
* DETALLEVENTA
* VENTA
* USUARIO

MODULOS:

* GESTION DE VENTA - registra la venta emitido por un usuario. 
* GESTION DE PRODUCTO - Se registra como se puede editar o eliminar un producto también se determina un stock o el estado del producto
* GESTION DE DETALLE VENTA - Donde se registra todos productos vendidos dentro de una una compra donde también se actualiza el stock al confirmar la venta.
* GESTION USUARIO - autentificación para un mejor control en cuento a la venta y control de stock
* GESTION DE CATEGORIA - Clasificación de producto

2 ATRIBUTOS DE CALIDAD: Idoneidad Funcional y Usabilidad de fácil manejo.
